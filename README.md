# 熟人局升级 · 微信小游戏演示

在微信开发者工具中导入项目根目录 `/Users/Adun/Upgrade`，不要导入内部的 minigame 或 miniprogram 目录。使用自己的微信小游戏 AppID，后端选择“不使用云服务”。配置已切换为 game，源码目录为 minigame/。保留当前已有 AppID，若不属于你的小游戏账号，请自行替换。若工具仍沿用旧类型，请关闭项目后重新导入。

体验流程：开始这一局 → 逐步随机发牌（有级牌可叫主）→ 无人叫主则投票 → 庄家扣8张底牌 → 完整出牌 → 每墩点击继续 → 真实结算 → 赢家使用互动卡 → 再来一局。你与正对面的陈皮为队友，小北与临时牌友为对手。

这是原生 Canvas 竖屏本地人机版：你与三名电脑按规则打完整局，不再使用固定手牌、三轮脚本或固定75分。实现单张、对子、拖拉机、强制跟牌、抓分、抠底和个人升级。电脑只根据自己手牌与公开领牌选择合法牌，策略较简单。主牌统一按主牌体系跟牌，不反主、不甩牌。

发牌时，你首次摸到某花色的可叫级牌且尚未定庄，会暂停等待你选择叫主或继续发牌。人机Demo中电脑不在发牌途中抢叫；若尚未定庄，发牌结束一定等待你最终选择叫庄或不叫，你不叫后电脑才参与。庄家拿到8张底牌后共33张，界面单独展示拿到的底牌；可从全部手牌中任选8张重新扣底，留下25张。

手牌支持点击多选；扣底需恰好8张。轮到你时可点“提示”选出一组合法牌，再点“出牌”，也可自己调整。非法出牌会保留手牌并提示原因。到A当局获徽章并从2继续；四名本地角色的等级和徽章在本机保存，不同步微信账号。前后台切换暂停自动行动，尚不支持退出应用恢复未结束的牌局。

抠底倍数：单张×2、对子×4、连续n对拖拉机×2^(n+1)。闲家方末墩获胜时加底分，庄家及其队友末墩获胜不加底分。总分可超过200，升级最多4级。41–79分庄家方守庄但双方不升级。

新增“四人好友联机”入口：支持可信登录、房间码/分享邀请、准备开局、完整对战、断线托管、持久化恢复、云端等级及共用互动卡。需要先部署测试云环境并填写公开环境配置，步骤见 [联机部署与验收](docs/online-deployment.md)。未部署时人机练习仍可正常使用；人机进度与联机成绩独立。

暂无陌生人匹配或真实语音。语音按钮只模拟开关，不申请麦克风权限，禁言卡只展示标记。旧版普通小程序保留在 miniprogram/，不再是当前启动入口。

自动化测试：先 `npm ci`，再 `npm test`，当前40项通过。包含规则边界、100种随机种子完整牌局的108张牌/200原始分守恒，320/390/768像素模拟Canvas流程，以及四WebSocket客户端整局、暗牌隔离、并发操作和服务恢复。自动化测试不能替代微信云环境及四账号真机验证。

牌局中持续展示本局等级来源，赢墩后展示主牌杀牌、级牌大小或同大先出等原因。真机验收步骤见 [牌局验收清单](docs/manual-round-checklist.md)，实际验收状态仍待确认。
