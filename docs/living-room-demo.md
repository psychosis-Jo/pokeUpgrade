# 客厅人机牌局样板

本次完成本地客户端接入，未上传或发布。好友房保留原有绘制流程；服务端、规则和存档结构未修改。

## 已实现

- 本地人机使用客厅背景、浅色面板、独立茶几和默认人物。
- 自己下方、队友上方、对手左右；行动座位有橙色提示，身份和剩余张数实时显示。
- 单张、对子和四张拖拉机按座位展示；超过四张时使用完整列表，避免多牌遮挡。
- 手牌点数与花色放大，选中上移并显示蓝色轮廓，推荐出牌保留。
- 叫主、投票、扣底和结算沿用现有交互，统一本地配色。
- 局中头像可叠加已有涂鸦效果；称号与禁言演示显示文字。完整人物动画及结算人物化尚未制作。
- 图片异步加载，加载失败仍保留文字座位与可操作牌面。
- 运行图片位于 minigame/assets/living-room，合计约272KB；高清源文件不在小游戏包内。

- 新增图片加载成功/失败后的重绘、素材路径存在及长出牌完整性测试。

## 用户验收

在现有微信开发者工具项目重新编译，进入人机练习；新画面需要客户端重新编译或预览，无需重新部署云服务。

请在iPhone检查：叫主按钮可点；庄家拿底后33张均可选择、选满8张才可确认；推荐与出牌可操作；普通出牌能看清归属；长拖拉机全部显示；结算后仍能开始下一局。图片加载与帧率、后台恢复及小屏实际触摸手感待真机验收。

当前仍使用375×760逻辑画布，矮屏会整体缩小；如真机字号或触摸区域仍偏小，需要下一轮按实测调整。当前是可玩样板，不是最终美术质量或完整首页改版。
